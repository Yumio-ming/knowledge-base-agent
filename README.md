# Knowledge Base Agent

💡

Building web products and AI-powered applications.

This repository contains production-minded projects, backend services, reusable packages, focused practice projects, and documentation across frontend development, Node.js, asynchronous workflows, and AI applications.

## Repository Structure

- `apps/` — Real projects and user-facing applications
- `docs/` — Notes, architecture decisions, and project retrospectives
- `packages/` — Shared libraries and reusable modules
- `practices/` — Focused exercises and technical experiments
- `servers/` — Backend services and APIs

## Principles

- Build for real user needs.
- Keep practice projects small and independently runnable.
- Document decisions, tradeoffs, and lessons learned.
- Measure AI features with repeatable examples.
- Keep secrets and private data out of the repository.
